What it does

🛠

MCP tool server

Calendar, notes, vision, memory and autonomous-loop tools with strict schema validation and a full audit trail.

🔎

Hybrid RAG

Dense semantic vectors + BM25/tsvector lexical search merged by Reciprocal Rank Fusion for precise context.

👁

CNN vision pipeline

Denoise, contrast, Sobel conv-feature maps, adaptive threshold, ROI boxes and OCR on whiteboards and scans.

⚡

Groq ReAct agent

Reason → call tools (in parallel) → observe → answer, running on Groq's ultra-fast Llama models.

🛡

Self-reflection guardrail

A second model pass checks every answer for hallucinated details and timezone/schedule mistakes.

🧠

Agent memory

Short-term, long-term and episodic memories recalled semantically across sessions.

🌐

3D context graph

Notes, events and documents as an interactive Three.js constellation linked by similarity and tags.

🐳

Production backend

TypeScript MCP server, Postgres + pgvector, Python CNN worker, all via Docker Compose.

FAQ

  

    
Where is my data stored?
In this browser's localStorage only. Use Audit → Export data to back it up, or Delete all data to wipe it.

    
Is my Groq key safe?
It is kept in localStorage and sent only to api.groq.com. Anyone with access to your browser profile could read it, so use a restricted key and don't enter it on shared devices.

    
Why does chat work without a key?
Offline mode runs local hybrid search over your notes, documents and upcoming events. The full ReAct agent with tool calls needs a Groq key.

    
How does the vision pipeline work in the browser?
Canvas grayscale → contrast stretch → box-blur denoise → Sobel convolution + ReLU + pooling feature maps → adaptive threshold → Tesseract.js OCR with line regions. The Docker version uses OpenCV + Tesseract.

    
Are embeddings truly semantic?
The browser build uses hashed word/character n-gram vectors fused with BM25, which is strong on keywords and fuzzy matches but not deep semantics. Plug a real embedding model into the backend for that.
